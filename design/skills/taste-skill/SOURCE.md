The anti-slop frontend framework for AI agents. A collection of SKILL.md instruction files (taste-skill, minimalist, brutalist, soft, redesign, image-to-code and more) that make coding agents infer the right design direction and ship interfaces that don't look templated.

## What was vendored
Only the functional skill content (SKILL.md files, references, scripts, data)
plus the upstream LICENSE was copied here. Per-agent duplicate directories,
tests, demos, screenshots, CLIs and build tooling from the original repo were
intentionally left out to keep this project lean. See
`../../README.md` for how to activate these as live Claude Code skills, or
re-clone the full repo from the upstream URL above.
